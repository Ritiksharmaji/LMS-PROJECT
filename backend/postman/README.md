# Postman collection

`Orbitly-API.postman_collection.json` covers every API area — auth, people and invites, catalog and authoring,
learning, grading, schedule, discussion, billing, media, notifications and analytics — with dummy data.
`Orbitly-Local.postman_environment.json` points it at a local API.

## Use it in Postman

1. **Import** both files.
2. Pick the **Orbitly · Local** environment and set `baseUrl` if your API isn't on `http://localhost:8080`.
3. Open the collection → **Run**. Run the folders in order: folder `00 · Setup` registers a brand-new organization
   (`postman-<number>`) each run, so nothing touches real data, and every later request uses the tokens and ids saved by
   earlier ones (collection variables).

Requests sign in as one of three people created by the run — `{{adminToken}}`, `{{instructorToken}}`,
`{{studentToken}}` — so you can also open any request on its own after a full run and send it again.

## What a run does

| Folder | Story |
|---|---|
| 00 Setup | Register organization (admin), allow self-signup |
| 01 Auth & account | Login, refresh, profile, forgot password |
| 02 People & invites | Invite an instructor, accept it, student signs up, search members |
| 03 Catalog & authoring | Category; free course with video, reading, quiz and assignment; paid course; publish both |
| 04 Public catalog | Categories, search, course page — no login |
| 05 Learning | Wishlist, enroll, player, complete lessons, pass the quiz, submit the assignment, review |
| 06 Grading | Grading queue, grade → course completes → verify the certificate |
| 07 Schedule | Schedule, reschedule and cancel a live session |
| 08 Discussion | Question, instructor reply, accepted answer, pin |
| 09 Billing | Checkout with the test provider, pay, refund, admin revenue |
| 10 Media | Signed upload flow (create → PUT bytes → complete), course resources |
| 11 Notifications | Notifications from the steps above, mark read, settings |
| 12 Analytics | Admin and instructor dashboards, CSV report |
| 13 Sign out | Logout |

## From the command line

```bash
npx newman run Orbitly-API.postman_collection.json -e Orbitly-Local.postman_environment.json --env-var baseUrl=http://localhost:8080
```

The collection is generated by `build_collection.py`; edit it and run `python3 build_collection.py .` to rebuild.
